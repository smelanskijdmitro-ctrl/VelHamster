# VelHamster Forum — запуск

Полноценный стартовый проект форума на Next.js + Supabase: регистрация, вход, профили, разделы, публикации администратора и жалобы игроков.

## Что реализовано
- Публичный просмотр форума.
- Регистрация по email/паролю и вход.
- Автоматический профиль с ролью `player`.
- Создание тем доступно только роли `admin` (проверка на сервере БД через RLS).
- Зарегистрированный игрок может отправить приватную жалобу.
- Администратор видит обращения и может закрывать их.
- Тёмный адаптивный дизайн VelHamster.

## 1. Создай проект Supabase
1. Открой https://supabase.com/ и создай новый проект.
2. В разделе SQL Editor выполни весь файл `supabase/schema.sql`.
3. В Project Settings → API скопируй Project URL и anon/public key.
4. Скопируй `.env.example` в `.env.local` и вставь значения:
   `NEXT_PUBLIC_SUPABASE_URL=...`
   `NEXT_PUBLIC_SUPABASE_ANON_KEY=...`
5. В Authentication → URL Configuration укажи адрес сайта. Для локальной разработки: `http://localhost:3000`.

## 2. Выдай себе права администратора
1. Зарегистрируйся на форуме через страницу `/register`.
2. В Supabase → SQL Editor выполни запрос, заменив email на свой:
   ```sql
   update public.profiles p
   set role = 'admin'
   from auth.users u
   where p.id = u.id and u.email = 'ТВОЙ_EMAIL';
   ```
3. Выйди и войди снова. Появится ссылка «Админка».
Никогда не добавляй роль в публичную форму регистрации. Роль назначается только владельцем проекта через SQL/защищённую админку.

## 3. Запусти локально
Нужен Node.js 20+.
```bash
npm install
cp .env.example .env.local
# заполни .env.local
npm run dev
```
Открой http://localhost:3000.

## 4. Размещение в интернете
Загрузи папку проекта в приватный GitHub-репозиторий, импортируй его в Vercel, добавь две переменные окружения из `.env.local` и нажми Deploy. В Supabase Authentication → URL Configuration добавь production URL и redirect URL.

## Перед публичным запуском
- Настрой SMTP в Supabase для надёжной доставки писем подтверждения.
- Добавь CAPTCHA/rate limiting для регистрации и формы жалоб.
- Настрой резервные копии базы и мониторинг.
- Добавь модераторские роли, если команда вырастет.
- Укажи реальные ссылки на Telegram-бота и политику конфиденциальности.
- Для полноценной переписки внутри тем потребуется отдельная таблица replies; сейчас реализованы публикации-объявления/темы и жалобы.
